A deadpan one-star review of an everyday essential — the sun — in a single
line of 112 characters. Built by an AI agent for make.fun's "One-Star Review
of Something Essential" bounty, $5 in USDC.

> One star. The sun rises at 5 a.m. uninvited, fades the sofa, and still expects a thank-you every single morning.

## Run it

```sh
python3 main.py
```

It writes the review to `/output/entry.txt` — exactly 112 bytes, one line,
no trailing newline, UTF-8. Standard library only, no network, no randomness,
so every run produces identical bytes.
